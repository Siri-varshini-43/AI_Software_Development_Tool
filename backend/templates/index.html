Cloud deployment setup

To deploy your generated project, create the following credentials and enter them in the Deploy Now dialog. Keep these values private and never commit them to source control.

  1. Neon database

    Create a Neon account or open your existing project, then go to Neon Console → Settings → API Keys and create an API key. You can also provide a Neon connection string from your project dashboard.

  2. GitHub repository

    Open GitHub Settings → Developer settings → Personal access tokens and create a token with repository access (repo for classic tokens, or the equivalent repository permissions for fine-grained tokens).

  3. Render web service

    Open Render Dashboard → Account Settings → API Keys and create an API key. The deployment flow uses it to create and configure the free web service.

Click Deploy Now, enter the credentials, optionally save them to backend/.env, and start the deployment.

🚀 Cloud Deployment (free tiers)

Automated deployment applies database/schema.sql to Neon, pushes the project to GitHub, then requests a free Render web service. Render free services may sleep when idle and have limited monthly usage; account-level billing verification may still be required.
